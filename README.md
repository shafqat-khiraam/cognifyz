🧑‍💻 Cognifyz Internship Projects
This repository contains various projects I developed during my internship at Cognifyz Technologies. These projects showcase my work in different domains, including task management, number pattern generation, and text-based game development.

📂 Projects
1. Pattern Generator Program
A Python program that generates various number patterns based on user input. It includes patterns like pyramid, square, left-aligned triangle, equilateral triangle, and diamond.

Features:
Generates pyramid, square, left-aligned triangle, equilateral triangle, and diamond patterns.

User is prompted to choose a pattern type and input the size.

Usage:
The user selects the pattern type and enters the size of the pattern.

The program generates and prints the selected pattern.

2. Task Manager Console App
A simple console-based task manager application that allows users to add, view, update, and delete tasks. Each task has a title, description, and status (Incomplete or Complete).

Features:
Add, view, update, and delete tasks.

Tasks include title, description, and status.

Simple interface for managing tasks.

Usage:
Users can choose options to create, read, update, or delete tasks.

Tasks are stored and displayed with their respective details.

3. Ultimate Temperature Converter
A Python program that converts temperatures between Celsius and Fahrenheit, providing a user-friendly interface and error handling.

Features:
Converts Celsius to Fahrenheit and vice versa.

Handles user input errors gracefully.

Displays conversion results with a friendly message.

Usage:
The user inputs a temperature and selects the direction of conversion.

The program calculates and displays the converted temperature.

4. Text-Based Space Adventure Game
A text-based space adventure game where the user makes decisions to explore different outcomes in the game. The game uses conditional statements to guide the user through various scenarios.

Features:
A simple text-based space adventure.

Players choose different options to progress in the game.

Story elements and challenges based on user choices.

Usage:
The user selects options to navigate through the game and advance the story.

5. CRUD Task Console App
A simple Python-based console application to perform basic CRUD (Create, Read, Update, Delete) operations on a list of tasks. The tasks include title, description, and status.

Features:
Perform CRUD operations on tasks.

User-friendly console interface to manage tasks.

Allows users to update or delete specific tasks by selecting their numbers.

Usage:
The user can create, read, update, or delete tasks through the console interface.

Ensure you have Python 3.x installed.

Run each project script individually.
